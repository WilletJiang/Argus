## What real requests uncovered

The initial C harness attempts failed **0/3 before any tools ran**. The authenticated
public Responses route returned HTTP 200 with valid SSE but no Content-Type header.
A separate urllib request confirmed the missing header. The provider had required
that header and rejected the response.

The fix accepts an absent Content-Type only through the existing strict SSE parser
and successful terminal response barrier. Present mismatched MIME, HTML, malformed
JSON and missing terminal responses still fail. Added network regression fixtures
cover all of these cases. Subscription usage-limit error codes now map to `AH_LIMIT`.

Each successful harness task also encountered one failed command because the
**evaluation adapter** incorrectly advertised a nonexistent Python path. The model
used the tool error to find an available Python and continued successfully. The
recorded times include this recovery; the released evaluation hint was corrected
after measurement. This was an evaluator error, not an intentionally injected test.

## Isolation and reproduction

The harness called the public Responses endpoint using independently authorized
ChatGPT-plan credentials; Codex used its normal ChatGPT-login route. The harness
model loop was entirely its own. Its evaluation-only exec adapter invoked
`codex sandbox -P :workspace` for OS isolation, not for inference. A local socket
probe verified that this profile denied network access to the executed program.
File tools retained their workspace-root policy. No real user documents or external
mail/actions were included. Credentials remained in the authorization/test process
memory and were not copied into the repository or reports.

The standalone kernel, HTTP/stream regressions and actual CLI contracts passed
ASan/UBSan after the fix. See [runner instructions](../README.md) to repeat with
fresh output directories and an explicitly authorized credential. A fair broader
comparison needs repeated runs, more difficult tasks, matched service conditions,
and independent review of failures; this report does not supply those results.
